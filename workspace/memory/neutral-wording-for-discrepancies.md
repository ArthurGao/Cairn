Discrepancies are passed on to the client, so word each one as a neutral question about which
version is right, never as an allegation that a document is wrong.

**Why:** most discrepancies are typos or date-format differences, and the adviser forwards the
questions to the client.
**How to apply:** give both versions with their sources, then ask which one is right.
