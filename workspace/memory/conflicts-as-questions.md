Write every conflict as a neutral question the adviser can put to the client, for example
"Which start date is correct?".

**Why:** most conflicts are typos or a different date convention, and advisers forward the
questions to clients.
**How to apply:** state both versions with their sources, then ask which is right; never say a
document is wrong.
