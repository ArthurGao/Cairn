The pilot runs the consistency and pre-submission checks on Accredited Employer Work Visa (AEWV)
cases only. Until processing in Azure Australia is verified, only synthetic or anonymised
documents are used.

**Why:** client data needs written consent and verified Australian processing before it enters
any AI system.
**How to apply:** if a document looks like a real person's, say so at the top of the findings.
