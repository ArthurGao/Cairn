These memory files of an advisers' assistant say nearly the same thing. Draft one memory that
replaces them all.

- `target_slug`: the slug of the file to keep (one of the files below); the others are archived.
- `description`: one line, at most 150 characters, that says when the memory matters.
- `body`: the merged Markdown body. Keep every rule, example and link that any file has; add
  nothing new. Every number, date, path, URL and back-ticked name must already appear in one of
  the files. For feedback and project memories keep a **Why:** line and a **How to apply:** line.
- `evidence`: short exact quotes from the files that the merged body rests on.

Never include secrets or any client's personal details.
